## Agent skills

### Issue tracker

Issues are tracked as local markdown files under `.scratch/<feature>/`. See `docs/agents/issue-tracker.md`.

### Triage labels

Default five-role vocabulary (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`). See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `GLOSSARY.md` + `docs/adr/` at the repo root. See `docs/agents/domain.md`.

## Język

Kod (identyfikatory, nazwy plików i katalogów, schemat bazy, kody błędów, nazwy testów) jest po angielsku. Komentarze, dokumentacja (GLOSSARY.md, ADR, spec, zadania) i teksty widoczne dla użytkownika są po polsku. Angielskie nazwy pojęć domenowych są zapisane w GLOSSARY.md (pole „W kodzie").
